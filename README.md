# deepseek-pool-ui

deepseek-pool-ui is a Python project.

## Requirements

Python 3.10 or newer and pip.

## Build

```bash
python -m venv .venv
source .venv/bin/activate
python -m pip install --upgrade pip
```

## Run

```bash
python backend/server.py
```

## Project structure

- `backend/`
- `frontend/`
